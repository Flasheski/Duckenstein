# Wolf3D - Epitech Project

* Ce projet consiste en la création d'un jeu de tir à la première personne (FPS) en 3D, utilisant la technique de **raycasting**, inspiré du classique Wolfenstein 3D.

## 🚀 Fonctionnalités

* **Moteur Raycasting** : Rendu 3D temps réel d'un environnement labyrinthique.
* **Système de jeu complet** :
    * Gestion des mouvements et des collisions.
    * Système d'armes et munitions.
    * Gestion de la santé du joueur.
* **Interface utilisateur (HUD)** : Affichage de la santé, des munitions et mini-map.
* **Audio et Visuel** : Effets sonores, textures, et système de particules pour les explosions/tirs.
* **Menu et Paramètres** : Options de volume, gestion de la résolution et mode plein écran.

## 🎮 Commandes

* **Déplacement** : `Z`, `Q`, `S`, `D` (ou flèches directionnelles).
* **Tir** : Clic gauche de la souris.
* **Interaction** : Touche `E` (portes/objets).
* **Menu Pause** : `Echap`.

## 🛠️ Installation

-> Pour compiler le projet, assurez-vous d'avoir la bibliothèque **CSFML** installée sur votre système.

1. **Cloner le dépôt** :
   ```bash
   git clone [URL_DU_DEPOT]
   ```

2. **Compiler le jeu** :
   ```bash
   make
   ```

3. **Lancer le helper pour savoir comment lancer le jeu** :
   ```bash
   ./wolf3d -h
   ```
